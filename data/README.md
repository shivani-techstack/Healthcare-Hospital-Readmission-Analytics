# Data folder

Download the source files from the official UCI page:
https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008

Expected files:
- `diabetic_data.csv`
- `IDS_mapping.csv`

Place them in this folder before running the Python starter script.

Privacy and Git hygiene:
- Do not commit raw patient-level data to a public GitHub repository.
- Add the CSV filenames to `.gitignore` if you decide to download them locally.
- Keep only documentation, code, and safe aggregate outputs in your public portfolio.
